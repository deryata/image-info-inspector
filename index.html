Image Info Inspector

A Chrome extension: right-click any image to see its file name, format, file size, dimensions, alt text, URLs and camera (EXIF) data.

Görsel Bilgi Denetçisi: herhangi bir görsele sağ tıklayarak dosya adını, biçimini, boyutunu, ölçülerini, alt metnini, adreslerini ve kamera (EXIF) bilgilerini görün.
